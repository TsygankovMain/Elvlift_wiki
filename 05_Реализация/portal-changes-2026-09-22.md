## Что выяснилось попутно

- **Поле «Потребность клиента» в сделке есть:** `UF_CRM_69CE5698493B8`, создано 02.04.2026. При конвертации переносится в 40 из 40 случаев. Вывод сверки 15.09 («поля нет, не переносится») ошибочен.
- **Источник при конвертации переносится** в 95 из 96 случаев. Пустой источник у 23 из 67 сделок с июля — это сделки, заведённые вручную, без лида.
- **Тип сделки не пуст ни у одной сделки.** Большинство на `SALE` («Проектирование») — это системный тип по умолчанию.
- **Системные источники переименованы:** `EMAIL` → «Звонок», `WEBFORM` → «E-mail», `RECOMMENDATION` → «Завод», `REPEAT_SALE` → «Сайт». Автоматика ставит системные коды, поэтому менеджер видит «чужой» источник. Кандидат на п. 7.
- **Шаблоны бизнес-процессов** источник и тип не меняют.
- **«Отчество» у контакта** — стандартное поле, обязательность включена в настройках. По REST не снимается, только в интерфейсе.
